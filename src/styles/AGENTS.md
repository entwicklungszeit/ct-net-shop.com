# AGENTS.md

## Theme

- **primary color sky-500**
- Sky for brand and actions
- Amber/Orange as the complementary warm accent
- Slate/Gray as the neutral base
- **Light and dark mode** – Users can toggle via the navigation. Initial mode follows system preference (`prefers-color-scheme`), selection is persisted in `localStorage.theme`. Dark theme aesthetic follows commit bb6b2b4: slate-950 background, slate-800/900 borders, sky-300/400 accents.
